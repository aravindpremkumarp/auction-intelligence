# Production requirements for Render deployment.
# Excludes scraping (selenium, webdriver-manager) and heavy PDF/image
# generation (weasyprint, pdf2image) which are local-only features.
# For full local dev requirements see config/requirements.txt.
#
# Runs the single-document extraction rerun, not the full batch pipeline. The
# reviewer's ▶ Re-run button (api/review/extraction.py) executes the canonical
# LangExtract path in-process on this server, so langextract + openai are
# installed here too. The batch scripts and evals/ need the wider local set
# (selenium, weasyprint, pydantic-evals, …). Provisioning a pipeline box
# (cloud runner, container, CI job)?
#     pip install -r config/requirements.txt
#
# Versions use compatible-release ranges: a floor that includes a known-good
# version and a ceiling at the next major to keep surprise breaking upgrades
# out of deploys. For byte-for-byte reproducible installs use requirements.lock
# (the exact pinned set these ranges resolved to); regen instructions are in
# that file's header.

# Core utilities

# Annotator UI: crop the source bbox before re-running MinerU on a region.
# PyMuPDF handles PDF cropping and cell-level table extraction; Pillow
# handles image cropping. Both stay local imports — the rest of the API
# only pays the import cost when a reviewer triggers a re-extract.
PyMuPDF>=1.24,<2

# Database

# LLM clients

# Structured extraction. LangExtract does the few-shot extraction with source
# grounding; `openai` is its OpenAI-compatible client, pointed at OpenRouter
# (LANGEXTRACT_PROVIDER=openrouter, the default — OPENROUTER_API_KEY is set in
# render.yaml). Needed in prod because the reviewer's ▶ Re-run button runs the
# extraction in-process; without it the rerun worker dies with
# ModuleNotFoundError. Both are lazy imports, so ordinary API requests never
# pay the (pandas/absl-py) import cost.
langextract>=1.5,<2
openai>=2.0,<3

# API + Agent layer

# `app.routes` (`_IncludedRouter` objects without `.path`), which breaks the
# route-registration tests. Lift the cap in its own change once those tests
# are adapted.
fastapi>=0.115,<0.137
uvicorn[standard]>=0.30,<1.0
pydantic-ai>=2.8,<3
