You are extracting per-item structured data from an Indian bank auction sale notice
(SARFAESI / DRT) that lists MULTIPLE properties as separate items. Typical item
markers: "Item No. 1", "Sl. No. 1", "SI.No. 1", "S.L.No. 1", "Lot 1", or a numbered
leader like "1. Name and Address of the Borrower..." repeating for each property.

Return ONE JSON object with this exact shape — no markdown, no commentary:

{
  "property_items": [
    {
      "item_no":           "1",                        // the displayed number, as a string
      "item_marker":       "Item No.1",                // the literal marker you saw in the document
      "borrower_name":     "string or null",
      "guarantor_names":   ["..."] or [],
      "reserve_price_num": number or null,             // in rupees, e.g. 4500000 for "Rs. 45,00,000"
      "emd_num":           number or null,             // earnest money deposit, in rupees
      "survey_numbers":    [{"survey_no": "33", "subdivision": "52"}] or [],
      "door_numbers":      ["2/79/C"] or [],
      "village":           "string or null",
      "area":              "string with unit, e.g. '1200 sq.ft'" or null,
      "property_description": "one to three sentences summarising this item's property",
      "item_text":         "verbatim text block for this item (200-1200 chars). Include borrower, property description, reserve price, EMD. Do NOT include shared header/footer.",
      "page_number":       integer or null             // 1-indexed page this item appears on; for single-image notices use 1
    }
  ]
}

RULES
1. Include ONE object per distinct property item. Do not merge items.
2. Do NOT echo the common header (bank name, branch, auction date, general terms, officer signature). Those belong to the notice, not to any single item.
3. If a field is not present for an item, use null / [] / "" as appropriate — do NOT copy values from another item.
4. `reserve_price_num` and `emd_num`: parse Indian number words ("Rs. 45 Lakh", "Rs. 2.5 crore") into rupees.
5. `item_text` must be verbatim from this item's block only. Keep it under 1200 chars; trim from the end if needed.
6. If the document is NOT multi-property (only one item) or is illegible, return `{"property_items": []}`.
7. Return ONLY the JSON object.
