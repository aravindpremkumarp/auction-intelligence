│   └── dl_done_*.txt / dl_results_*.jsonl  Download tracking files

│   ├── (root files)                   ~2,405 misc downloaded files
│   ├── live_properties/               ALL property downloads (growing)
│   └── tn_properties/                 TN-specific downloads (~2,560 files, synced subset)
│
├── scrapers/
│   ├── phase1_harvest_urls.py         TWO-PHASE SCRAPER - Phase 1: fast listing crawl
│   │                                  Paginates live-properties, collects new URLs only
│   │                                  Writes to data/pending_urls.txt
│   │                                  Smart early-stop: 5 consecutive stale pages = done
│   ├── phase2_scrape_details.py       TWO-PHASE SCRAPER - Phase 2: parallel detail scrape
│   │                                  Reads pending_urls.txt, uses N_WORKERS=3 Selenium
│   │                                  drivers in parallel threads. Downloads sale notices
│   │                                  & PDFs, links filenames to each property record.
│   │                                  Fields: Downloads (string) + downloads_list (array)
│   ├── fast_eauctions_scraper.py      Legacy single-pass scraper (deprecated, kept as ref)
│   ├── utils.py                       setup_driver() with cached ChromeDriver path
│   │                                  (thread-safe lock so parallel workers don't race)
│   └── scraper_controls:
│       scraper_stop.lock  → create to stop gracefully
│       scraper_pause.lock → create to pause, delete to resume
│
├── scripts/
│   ├── prepare_tn_data.py             Filters live_eauction_data.jsonl -> tn_auction_data.jsonl
│   ├── convert_to_excel.py            Converts live_eauction_data.jsonl -> .xlsx
│   ├── load_tn_to_neo4j.py            Loads TN data into Neo4j graph database
│   ├── link_reauctions.py             Links re-auctioned properties in Neo4j
│   ├── dedupe_documents.py            Deduplicates download documents
│   ├── upload_downloads_to_r2.py      Uploads downloads to Cloudflare R2
│   └── ... (other utility scripts)
│
├── pipeline/                          Orchestration pipeline code
├── api/                               REST API code
├── web/                               Frontend web application
├── tracking/                          Download progress tracking
└── config/                            Configuration files

DATA FLOW
---------
1. phase1_harvest_urls.py  -> data/pending_urls.txt  (new property URLs only)
2. phase2_scrape_details.py -> live_eauction_data.jsonl (parallel detail scrape + downloads)
3. prepare_tn_data.py      -> tn_auction_data.jsonl (TN filtered + cleaned)
4. Excel export            -> tn_auction_data.xlsx
5. tn_properties sync      -> copies TN-specific files from live_properties/
6. load_tn_to_neo4j.py     -> loads into Neo4j

TWO-PHASE SCRAPER USAGE
------------------------
  # Phase 1: collect new URLs (~30-45 min for full site)
  python -u scrapers/phase1_harvest_urls.py

  # Phase 2: scrape details in parallel (3 workers)
  python -u scrapers/phase2_scrape_details.py
