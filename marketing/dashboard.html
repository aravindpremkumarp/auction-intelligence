the update protocol▶

this file is the single source of truth for marketing-system state. everything on the page renders from one data block — MARKETING_DATA at the top of the script in this file. the renderer below it is generic and lays out new nodes, lanes and edges automatically.

  1. ship or change anything marketing-related → edit MARKETING_DATA in the same PR: touch nodes / edges / kpis / pillars / roadmap / metrics / risks.
  2. prepend a changelog entry and bump meta.updated.
  3. open the file in a browser: no console errors, graph renders, a node click opens the panel, table view works.

the standing rule lives in CLAUDE.md → marketing dashboard, so every future session inherits it. statuses: live shipped & operating · building partially working · ready built, waiting on a human or trigger · planned spec'd only · held deliberately parked.
